# README graphics

Original presentation graphics by Kerem Kilic (Ellic Studio):

- `introducing-saadet.png`: project introduction; the waveforms are conceptual illustrations, not measured audio.
- `engine-map.png`: simplified architecture highlights, not a signal-flow schematic.
- `connections.png`: MIDI and audio connections with their supported directions.
- `quick-start.png`: controls alongside native firmware UI captures.

The cheat sheet uses unretouched 240 × 240 screens rendered by
[`tests/ui_harness.c`](../../tests/ui_harness.c), enlarged exactly 2× with nearest-neighbour sampling.
These are host renders of the actual UI, not photographs of an FM-1 display.
[`capture-provenance.json`](capture-provenance.json) records their source revision and checks.

Native interface work includes Saadet/Melodee by Kerem Kilic (Ellic Studio) and
retained Felucca portions by Leo Kuroshita (@kurogedelic), Hügelton Instruments.
Original source, font and third-party notices remain in place; see
[`LICENSING.md`](../../LICENSING.md).
